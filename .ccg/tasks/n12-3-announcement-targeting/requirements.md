# N12.3 运营公告定向投放

## Scope

- 公告支持按用户状态、角色、创建时间和是否付费定向展示。
- 普通用户只能看到命中当前账号条件的公告。
- 后台可以配置定向条件，并预览命中人数。
- 默认公告行为不变，旧公告视为全量可见。

## Acceptance

- `audience_json` 默认 `{}`，兼容旧数据。
- 后端命中规则覆盖 status / role / createdAfter / createdBefore / paidOnly。
- 后台创建和编辑公告可保存定向条件。
- 后台列表或表单展示命中预览。
- 补后端命中规则测试。
- 不提交、不归档。
