# 移除默认风格和常用风格功能

## 背景

默认风格会全局追加提示词，常用风格会在创作页显式带入风格 prompt 和参考图。对于一个不局限于固定审美或固定项目的生图平台，这类设置容易污染用户的当前创作目标。

## 目标

- 偏好设置只保留生成参数、导出参数和审核策略。
- 移除默认风格输入，不再保存或追加 `stylePrompt`。
- 移除常用风格 / 参考图组管理，不再在创作页、历史页、详情页展示或使用。
- 保留历史资产整理能力：文件夹、标签、收藏、筛选不受影响。
- 保持已有生成、图生图、对话创作、图片工具链路可用。

## 非目标

- 不清理用户 localStorage 中旧字段，只是不再读取和写入。
- 不移除文件夹、标签、收藏。
- 不调整生成模型能力。
