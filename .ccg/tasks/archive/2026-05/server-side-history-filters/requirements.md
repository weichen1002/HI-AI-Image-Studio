# 历史资产筛选服务端化

## 背景

历史页已经支持服务端分页、搜索和类型筛选，但文件夹和标签仍在当前页内做本地过滤。分页后，本地过滤会导致结果不完整：用户选择某个文件夹或标签时，只能看到当前页命中的记录，而不是全库命中的记录。

## 目标

- `GET /api/images` 支持 `folder` 和 `tag` 查询参数。
- 历史页切换文件夹或标签时重置到第一页并请求服务端。
- 前端不再对服务端分页结果重复做文件夹/标签过滤，只保留收藏等纯本地筛选。
- 保持现有分页、搜索、类型筛选、会话链聚合和批量整理逻辑可用。
- 增加仓储层测试，覆盖 folder/tag、未归档/未打标签、用户隔离。

## 非目标

- 不改数据库结构。
- 不引入新的资产索引表。
- 不把收藏筛选迁移到服务端。
- 不重构历史页整体布局。

## 模型能力判断

该能力是资产库查询能力，不依赖图像生成模型能力。
