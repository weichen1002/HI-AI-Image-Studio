管理中心（方向 A）细化：表格 + 详情抽屉

请选择你更希望的“信息架构/抽屉结构/交互增强”。我会按你的选择把 3 个管理页面统一成一致体验。

1) 信息架构（单选）
A

保留 3 页（用户/流水/管理员）

用户管理页用抽屉做高频操作；流水页支持按 userId 查询；管理员页仅 superadmin。

B

合并流水：主要在抽屉里看

“账务流水”页降级为全局审计/搜索（可选），日常从用户抽屉直接看流水。

C

管理中心首页（导航卡片）

进入管理中心先看到 3 张功能卡片；再进入具体页面。更“后台系统”感觉。

2) 抽屉结构（单选）
A

Tab：概览 / 账务 / 流水 / 权限

信息清晰；流水可分页；权限 Tab 仅 superadmin 可见。

B

分区卡片：在一屏滚动完成

更快；适合小屏；但当流水很多时会长。

C

顶部快操作 + 下方流水

把“改 plan/调账/改角色”做成顶部快捷按钮；下面只放流水列表。

3) 交互增强（可多选）

这些是“用起来顺手”的关键点：减少弹窗、减少跳转、减少复制粘贴。

1

点击行打开抽屉

右侧抽屉固定宽度；Esc 关闭；列表滚动位置不丢。

2

Plan/Role 行内变更

下拉选择后立即保存，右上角 toast 提示结果。

3

调账在抽屉完成（不弹 modal）

一个 amount + reason 输入框，确认后流水即时追加。

4

一键复制 userId / username

减少手工复制；复制成功 toast；支持快捷键。

5

筛选：plan / role / 余额区间

运营常用；并支持“仅余额不足”快速筛选。

6

批量操作（勾选多用户）

批量调账/批量设为 pro 等；适合后期发活动。

默认推荐组合

IA 选 A 或 B；抽屉选 A（Tabs）；交互建议至少勾选 1/2/3/4。
